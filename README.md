# St Mugaga SS Jalamba School Website

A school website for St Mugaga Secondary School, Jalamba.

## Features
- Public pages for the school
- Admin portal for managing content and printing results

## Tech Stack
- PHP
- MySQL
- HTML/CSS/JavaScript

## Running Locally
1. Install XAMPP and start Apache and MySQL.
2. Copy the project folder into `htdocs`.
3. Import the database and update the connection settings.
4. Open `http://localhost/st-mugaga-ss` in your browser.
